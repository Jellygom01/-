# Prompt Archive Upgrade

## 포함 기능
- 카테고리 탭, 검색, 프롬프트/네거티브 프롬프트 복사
- 이미지 업로드 미리보기(브라우저에서 축소)
- 즐겨찾기
- 자료 추가/수정/삭제
- JSON 자료 내보내기/가져오기

## 중요한 저장 방식
이 버전은 GitHub Pages용 정적 사이트입니다. 자료 편집과 즐겨찾기는 현재 기기의 브라우저에 저장됩니다. 편집한 자료가 다른 방문자에게 자동으로 공개되지는 않습니다.
공개 사이트에 변경 사항을 반영하려면 관리자 도구에서 `자료 내보내기`를 눌러 `prompts.json`을 내려받고, 별도 서버/저장소 연동을 추가하거나 웹사이트 코드를 수정해 공개 자료를 갱신해야 합니다.
이 파일은 간단한 개인용 편집 화면이며 인증/권한 보안을 제공하지 않습니다. 민감한 자료를 보호하는 용도로 사용하지 마세요.

## GitHub Pages에 적용
1. ZIP을 압축 해제합니다.
2. `index.html`을 GitHub 저장소의 루트에 업로드합니다. 기존 `index.html`이 있다면 먼저 백업하세요.
3. Pages 설정은 이미 정상 작동 중이라면 다시 바꿀 필요가 없습니다.
